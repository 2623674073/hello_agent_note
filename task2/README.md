3、其他的就是项目管理

对于项目结构，我的理解还比较浅薄。

基础认知就是，不同项目是不一样的，
对于当前的这个项目来说，它只分为 Core、Agent，还有 Tool（工具）三个目录结构，定位也很简单，就是把不同层级划分开：
• Core：里面是实现的核心代码
• Agent：里面是不同风格的 Agent 代码实现
• Tool：主要是工具的注册和封装，还有一些基础 Agent 的实现，以及基础工具调用封装

对于更高级别的话，一般会分得更细：
• Core：核心文件，里面包含服务启动入口
• config：一些配置文件会写在这里
• service
• model：因为会有大量的数据模型需要去配置
